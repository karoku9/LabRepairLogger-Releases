02 / ARCHIVIO

Cifratura database

Richiede verifica

Questa scelta riguarda solo il database del server. Il database locale della Nightly resta SQLCipher. Cambiare configurazione non converte automaticamente un archivio esistente.

◇

SQLite standard

Database server non cifrato. Richiede comunque accesso autenticato e backup.

sqlCipherEnabled: false
◆

SQLCipher

Database server cifrato. Richiede una chiave separata e una migrazione verificata.

sqlCipherEnabled: true
Stato live non disponibile da Pages. Per modificare il valore desiderato usa il file nella repo privata. Il cambio del database esistente richiede una procedura di migrazione, backup e conferma, non un interruttore live.
